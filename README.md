# GitHub Profile Recreation (React)

A responsive GitHub-profile-inspired page built from reusable React components.

link: https://fatemorningstar.github.io/Fatemorningstar-react./

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

## Component structure

```text
src/
├── components/
│   ├── Navbar.jsx
│   ├── ProfileHeader.jsx
│   ├── ProfileSidebar.jsx
│   ├── RepositoryCard.jsx
│   ├── RepositoryList.jsx
│   └── ContributionGraph.jsx
├── data/
│   └── repositories.js
├── App.jsx
├── main.jsx
└── style.css
```
